# CalcNest – Client-Side Financial Calculator Suite

CalcNest is a lightweight, privacy-focused collection of financial calculators designed to model wealth accumulation, debt amortization, and tax liability without intrusive ads or user data tracking.

🌐 **Live Platform:** [https://calcnest.blog/](https://calcnest.blog/)  
🧩 **Free Embed Widgets:** [CalcNest Embeddable Widgets](https://calcnest.blog/calcnest-blog-embed-widgets/)

---

## 🚀 Key Calculators

- **Step-Up SIP Calculator:** Forecast compound growth with dynamic annual contribution steps. [Try SIP Engine](https://calcnest.blog/)
- **Amortized EMI Calculator:** Visual breakdowns of principal repayment vs. total interest over custom loan tenures.
- **Salary / Take-Home Estimator:** Accurate deductions and net salary modeling based on current fiscal slabs.
- **GST & Commercial Math:** Fast single-click GST extraction and forward calculations.

---

## 🔒 Architecture & Privacy

- **100% Client-Side:** Evaluated directly in the browser using native JavaScript algorithms.
- **Zero Telemetry / Zero Storage:** No financial inputs, loan sizes, or personal income numbers are sent to any server.
